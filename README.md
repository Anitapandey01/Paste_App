# Paste App

**Live Demo:** https://pasteapp-git-main-anitas-projects-595d6830.vercel.app/

A React-based Paste App built using React and Vite. It allows users to create, view, edit, delete, and manage text pastes easily.

## Tech Stack

- React.js
- Vite
- Redux Toolkit
- React Router DOM
- Tailwind CSS
- Local Storage

## Features

- Create new pastes
- View saved pastes
- Edit and update existing pastes
- Delete pastes
- Copy paste content
- Search and manage pastes
- Persistent storage using Local Storage

## Getting Started

Clone the repository:

```bash
git clone https://github.com/Anitapandey01/Paste_App.git
```

Navigate to the project folder:

```bash
cd paste_app
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## Build

To create a production build:

```bash
npm run build
```
